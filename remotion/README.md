# Chicago Incentive Explorer Product Demo

Horizontal Remotion product demo for the platform.

## Commands

```bash
npm run video:preview
npm run video:render
```

The render command writes:

```text
out/chicago-incentive-explorer-demo.mp4
```

## Composition

- `ChicagoIncentiveExplorerDemo`
- 1920x1080
- 30 FPS
- 54 seconds

The closing QR code points to `https://chicagoincentiveexplorer.com`.
